001 / Self-hosted · MCP · Obsidian

Obsidian MCP Server

把一份 Obsidian Markdown 仓库，变成多个 AI Agent 可以共享的工作台。同一套记忆、独立凭据、可归属的写入，以及不会静默覆盖的并发编辑。

MIT Self-hosted Streamable HTTP MCP
01

一份记忆，多个 Agent

所有 Agent 通过同一个自托管端点读写同一份 Vault，不需要导出或同步。

02

每个 Agent 独立凭据

OAuth 或限定范围的 API Key，按 Vault 与读写权限收窄，可以单独撤销。

03

写入有归属，冲突不静默

写入携带作者与模型，revision 校验拒绝过期编辑，而不是悄悄覆盖。

04

浏览器工作台

阅读、源码、实时预览三种模式；frontmatter、搜索、Skills 与发布都在同一处。

查看项目主页 ↗ 源码（MIT）↗

Note 它不是多点同步产品：异地 Agent 通过 HTTPS、VPN 或隧道接入同一个端点。

002 / Android · Kotlin · Local-first

Pocket Pi

面向 pi 的本地优先 Android 客户端。Termux 内的桥通过 HTTP + SSE 连接 pi RPC，原生 Compose 界面提供终端级对话、多机切换与本地会话。项目主页含 9 屏静态截图导览。

MIT Android Kotlin / Compose
01

在手机上运行

Termux 承载桥与真实的 pi 进程，App 通过回环地址连接；会话写入本地 JSONL。

02

终端级界面

原生 Compose 对齐 pi TUI 的排版与工具状态；流式增量、可折叠思考、运行中 steer / queue。

03

多机切换

回环、当前网段与已保存主机在同一列表；LAN / Tailscale 路线合并，休眠机器可 SSH 唤醒。

04

会话工作区

按项目目录分组，支持排序、筛选、分叉、会话树与上下文环。

查看项目主页 ↗ 源码（MIT）↗

Arch App（Kotlin / Compose） ↔ HTTP + SSE ↔ Termux 桥（Node） ↔ pi --mode rpc ↔ 本地会话 JSONL。
